# Born2beRoot

A Linux system-administration project that builds and secures a minimal Debian server inside a virtual machine.

## What it covers

- Virtual machine and server setup
- Users, groups, password policies, and sudo rules
- SSH configuration and root-login restrictions
- UFW firewall configuration
- AppArmor and system monitoring
- Encrypted partitions and LVM

## Access

SSH is configured on port 4242:

```bash
ssh amigdadi@localhost -p 4242
```
